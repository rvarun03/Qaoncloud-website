## Getting Started

First, run the development server:

```bash

yarn dev
# or
pnpm dev
```

## Production SMTP Test

Configure these server-side environment variables in the deployment platform:

```bash
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=varun@qaoncloud.com
SMTP_PASS=your-google-app-password
# Optional; defaults to SMTP_USER
SMTP_TEST_TO_EMAIL=varun@qaoncloud.com
```

After deployment, open the test page:

```text
https://your-domain.com/smtp-test
```

Click **Send Test Email**. The endpoint sends only to `SMTP_TEST_TO_EMAIL` (or `SMTP_USER`) and returns `503` when required configuration is missing, without affecting the rest of the site.
